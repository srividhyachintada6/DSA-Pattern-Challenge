# Day 2 — Two Pointers

## What is Two Pointers?

Two Pointers is a technique where we use two indexes/pointers to move through an array or string efficiently.

Common forms:

* Left → Right
* Right → Left
* Both pointers moving toward each other
* Slow → Fast
